# NPS-WEB

This repository hosts my personal academic website, which is deployed at [npsweeney.co.uk](https://npsweeney.co.uk). Its source, CV, publication data, and assets are in [`live/`](live/).

The [`template/`](template/) folder is a separate, generic starter for other academics to use. It includes the website structure, an interactive publications table, starter academic and policy BibTeX files, and a small script that turns those BibTeX records into the publication data used by the site. See [`template/README.md`](template/README.md) for setup instructions.
